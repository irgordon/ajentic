AJENTIC local help

AJENTIC helps you look at proposed AI work, recorded checks, and review choices separately, instead of trusting an answer because it sounds confident.

This local example uses pre-made data. Start with Getting started to create a sample, read its explanation, and record one review choice. No AI-service account or secret key is needed.

The example is local-only and non-production. Refreshing the page clears its in-memory session; it is not saved work.

These help pages are explanatory only. They do not grant authority or approve use.

For separate user, developer, and maintainer guides, visit the full documentation. That link opens repository documentation and needs internet access; these bundled help pages remain local.
