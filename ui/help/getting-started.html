Getting started

This local UI is a sample workflow, not a live AI chat service. It uses a pre-written example so you can practice reviewing a draft and recording a choice.

If the page is not running, ask the person setting it up to follow the repository installation guide. After dependencies are installed, they can run npm run dev from the UI folder and open the printed local browser address on the same computer.

Your first review

  1. Recognize Local Demo and Sample Comparison. Before/After is a pre-made illustration; no files have been written.
  2. Click Run Sample, then select Result. Read the sample under Draft Output and expand Check Details to understand what was checked.
  3. Choose Record Approval or Reject Draft under Review Decision. This records a local choice only, not execution or release permission.
  4. Confirm the footer says your choice was recorded. Both buttons then become disabled.
  5. Select Activity, then expand Decision History. Decision Count becomes 1 and the record matches your choice.

Only one decision is accepted for that sample in a session. Use View / Reset Example or refresh to practice the other choice. This clears the in-memory example and notes, not a saved record.

Compare shows the illustration; Result shows the built-in draft. Review Notes stays in this page only. Attachments Not Connected is disabled and cannot upload files.

Use View / Checks for missing or blocked evidence and View / Developer Details for advanced local tests. If a check shows Unknown status, inspect its raw details; unknown does not mean successful.

The help is explanatory. The example is local-only and non-production, and its display checks do not prove that AI-generated facts are correct.
