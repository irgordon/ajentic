Getting started

This local UI is a sample workflow, not a live AI chat service. It uses a pre-written example so you can practice reviewing a draft and recording a choice.

If the page is not running, ask the person setting it up to follow the repository installation guide. After dependencies are installed, they can run npm run dev from the UI folder and open the printed local browser address on the same computer.

Your first review

  1. Find Run local simulation near Bounded context and click it. Bounded context means the limited information supplied to the example.
  2. Read Candidate output, which is the sample draft, and Validation / policy result, which explains the recorded checks.
  3. Select Approve or Reject under Operator controls. This only records your local choice; it does not publish, send, or execute work.
  4. Confirm Selected operator intent matches your choice. Intent means the choice you asked the example to record. Look for its entry in Run history / timeline.
  5. Check Replay / status projection for decision count 1. This is a summary of the recorded choice, not a repeat of a real-world action.

Only one decision is accepted for that sample in a session. A second choice is rejected as a duplicate. Refresh and start the simulation again to practice the other choice; refreshing clears the local example.

Some labels still show Unknown status because their technical value has no friendly translation. After a decision, use Selected operator intent and the timeline to confirm what was recorded. Unknown does not mean successful.

The help is explanatory. The example is local-only and non-production, and its display checks do not prove that AI-generated facts are correct.
