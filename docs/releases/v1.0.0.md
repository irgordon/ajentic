# AJENTIC v1.0.0

Status: final v1.0.0 GitHub Release.

Source RC: v1.0.0-rc.1

Final tag: v1.0.0

Final commit: recorded by the final-release workflow.

## What Is Included

- Read-only local browser UI.
- Deterministic local testing shell.
- Final candidate bundle.
- Rust release executable artifact.
- UI `dist` files.
- Checksum evidence.
- SBOM evidence.
- Provenance evidence.
- GitHub artifact attestation evidence if generated by the final workflow.

## What Is Not Included

- No npm publication.
- No Cargo publication.
- No installer.
- No update channel.
- No deployment.
- No OS signing.
- No notarization.

- Final tag: `v1.0.0`

## Branch Protection or Ruleset Status

Branch protection or ruleset status must be verified before final workflow dispatch.

If branch protection or rulesets are disabled, the final release requires an explicit final-release Owner exception. The RC-only exception does not authorize final release execution.

## Package Metadata Policy

The final GitHub Release identity is `v1.0.0`.

Package metadata remains separately governed in Phase 194. The `core` crate and browser UI package metadata are not changed to `1.0.0` by this release note. Package metadata alignment does not imply npm or Cargo package publication.

## Governance Note

Rust remains authority.

TypeScript remains visibility.

Python remains adaptation.

Bash remains glue.

Release assets, checksums, SBOM evidence, provenance evidence, and artifact attestations are review evidence. They do not become governance authority, deployment approval, package publication approval, installer approval, update-channel approval, or UI authority.
